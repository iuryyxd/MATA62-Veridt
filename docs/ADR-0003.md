# ADR 0003 - Particionamento por domínio

### Contexto

Necessidade da elaboração dos componentes candidatos e os módulos para a aplicação, escolhendo entre o particionamento por domínio e técnico.

### Decisão

Escolha do particionamento do domínio como particionamento da arquitetura.

### Alternativas consideradas

1. Particionamento técnico: não foi escolhida devido a escolha do estilo arquitetural (ver ADR-0001), uma vez que o monólito modular funciona com a ideia do particionamento por domínio.

### Justificativa

1. Sua localidade para arquivos pertencentes ao mesmo módulo é baixa, melhorando a manutenção da codebase.
2. É o mais alinhado para o estilo arquitetural escolhido (ADR-0001).
3. Facilidade para migrar os componentes para uma arquitetura distribuída.
